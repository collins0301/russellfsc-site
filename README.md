# Dive CFO static website

This package uses the approved 1672×941 homepage design image directly so the homepage appearance is not redesigned or altered. Invisible clickable hotspots are layered over the visible navigation, CTA buttons, and service cards.

## Upload to GitHub
1. Open your GitHub repository.
2. Choose **Add file → Upload files**.
3. Upload **all files and the `assets` folder** from this package. Do not upload only the ZIP.
4. Click **Commit changes**.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Branch: **main**. Folder: **/(root)**. Click **Save**.
8. GitHub will provide a `github.io` website URL after deployment.

## Files
- `index.html` — homepage
- `styles.css` — exact-image homepage sizing and invisible clickable areas
- `assets/dive-cfo-homepage.png` — approved homepage image, unchanged
- `services.html`, `about.html`, `resources.html`, `contact.html` — temporary functional secondary pages

The secondary pages can be redesigned later without changing the approved homepage.
